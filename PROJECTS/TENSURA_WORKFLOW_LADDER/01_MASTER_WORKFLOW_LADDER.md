# Master Workflow Ladder
## Governing rules
1. The ladder is mandatory. A later stage cannot begin until its prerequisites are verified.
2. Every participating file begins with its own Workflow Ladder block identifying the complete sequence, exact file stage, prerequisites, required actions, completion evidence/status and exact next destination/action.
3. This master controls the sequence. A conflicting copied header is a stop condition.
4. Every stage produces an artifact or recorded verification. "I remember doing it" is not evidence.
5. Read actual source and project files, not memory or summaries where full reading is required.
6. Record blockers honestly. Never mark unread or unverified work complete.
7. All drafts are non-canon. User approval is the only route to canon promotion.
8. This is a manual ChatGPT workflow, not an agent system.

## Mandatory feedback loops
- After Stage 09: log drafting and first-review failures.
- After Stage 11: compare first review with independent audit; log escaped defects.
- After Stage 12: assess process compliance and whether the ladder enabled a bypass.
- After Stage 14: update canon ledgers only following approval.
- Stage 15 improves future execution. It never silently changes story canon.

## Stop conditions
Stop if a required file is missing, source coverage is uncertain, source and project canon conflict, knowledge state is unclear, drafts differ, workflow version mismatches, approval is absent or protected mutation lacks explicit permission.

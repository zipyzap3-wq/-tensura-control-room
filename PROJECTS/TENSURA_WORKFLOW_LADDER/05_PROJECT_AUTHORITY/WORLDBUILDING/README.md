## Rules
1. A world bible describes the place; a character sheet describes what the character can do; an arc plan describes what happens in the story.
2. Do not duplicate full descriptions across those authorities. Link to the owning document.
3. Every worldbuilding fact must be labeled as user-directed, proposed, open, source-verified or canon-approved.
4. Never invent exact coordinates, seed strings, distances, population counts, loot, time ratios or world-generation rules.
5. Update the map register and decision register when geography or world mechanics are decided.
6. All working worldbuilding remains non-canon until the user explicitly approves it.

# Chapter Production Workflow
## Before writing
1. Confirm workflow version and session checkpoint.
2. Read master ladder and exact next-step file.
3. Read actual source chunks in full, including setup and look-ahead.
4. Read relevant approved prior chapters in full.
5. Read character dossiers and time-state cards for major participants.
6. Read timeline, knowledge, character state, open threads and conflict register.
7. Define source-locked events, divergence permissions and unresolved choices.
8. Create chapter packet: purpose, source anchor, event sequence, cast, POV, objectives, scene outline, emotional movement, continuity risks, ending and handoff.
9. Obtain approval for decisions reserved to the user.

## Drafting order and location
- Creative chapter draft is first written inside the ChatGPT conversation, only after upstream gates.
- Then create a separate non-canon GitHub draft file from that same text.
- GitHub draft is the working file for first review and correction.
- Present the corrected GitHub draft in ChatGPT. The two versions must match exactly.
- The draft remains non-canon regardless of polish or audit status.

## First review
Check source sequence/page fidelity; characterization, voice, knowledge and time-appropriate abilities; cause/effect, staging and tactical logic; POV and information control; time/place/injuries/resources/promises/relationships/open threads; prose rhythm, dialogue, monologue/action/narration balance; chapter purpose, emotional movement and ending; all ladder stages and evidence. Correct GitHub draft and record changes.

## Second audit and approval
Present corrected matching text in ChatGPT. Independently re-read source, canon, packet and chapter. Record defects, severity, correction and workflow gap. Present chapter, source anchors, path map and both audits. Wait for explicit user decision. Silence is not approval.

## Canon promotion
Only after explicit approval: promote approved text, update chronology/character state/knowledge/open threads/chapter tracker, preserve draft and audits, and record approval.

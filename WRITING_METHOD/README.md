# Living Story Method integration

This repository carries a local, portable copy of **The Living Story Method (LSM) v1.0.0** so writing assistants can apply it without relying on external chat memory.

- [Master protocol](LSM_MASTER_PROTOCOL.md): complete method, including scene design, character vitality, immersion, dialogue, worldbuilding, pacing, emotional resonance, continuity, revision, and AI workflow.
- [Project adapter](PROJECT_ADAPTER.md): how to apply the method here without overriding this repository's canon, technical scope, or existing rules.

## Required use
1. Read the repository's own governing instructions first.
2. Read the actual relevant story/source files, not only summaries, before drafting.
3. Apply the LSM as a craft layer, especially its POV and narrative perspective engine.
4. Follow the project adapter and preserve protected content, canon status, and approval boundaries.
5. Check the draft against the scene and chapter quality gates before presenting it.

## Versioning
The copies currently identify themselves as LSM 1.0.0. Keep the master protocol consistent across repositories when updating the method. Project adapters are intentionally different because each repository has its own constraints.
